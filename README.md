## How I Document Testing

1. Define the objective, testing scope, and environment.
2. Write test cases with clear steps and expected results.
3. Execute positive and negative scenarios.
4. Record pass/fail results and supporting evidence.
5. Report issues with reproducible steps and expected vs. actual behavior.
6. Summarize findings, limitations, and suggested next checks.
